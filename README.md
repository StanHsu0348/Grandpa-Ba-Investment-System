# 巴爺爺選股 — 五點好企業原則篩選系統

以陳柏瑄老師課程《巴菲特企業經營法》cht14 P40「濃縮版：5 點好企業原則」為核心邏輯，
提供可互動調整篩選條件的選股系統。分為**台股**與**美股**兩個完全獨立的頁面
（分別讀入 `data/twlist.xlsx`、`data/uslist.xlsx`），兩者資料與篩選條件互不影響。

完整規格請見 [SPEC.md](SPEC.md)。

## 安裝

```bash
pip install -r requirements.txt
```

## 執行

```bash
streamlit run app.py
```

啟動後瀏覽器會自動開啟 `http://localhost:8501`，左側導覽選單可切換「🇹🇼 台股」／「🇺🇸 美股」頁面。

## 更新股票清單資料

兩種方式擇一（台股、美股分別對應各自的檔案，互不影響）：

1. 直接覆蓋 `data/twlist.xlsx`（台股）或 `data/uslist.xlsx`（美股），檔名維持不變，重新整理網頁即可套用新資料。
2. 在對應頁面側邊欄「資料來源」區使用 `上傳最新股票清單 Excel` 上傳新檔案，當次執行改用上傳的資料，不影響 `data/` 目錄中的原始檔。

若同時提供兩種資料來源，優先使用上傳的檔案。

## 視覺風格

介面採 Apple 風格重新設計：白色／淺灰兩層畫布＋卡片式區塊、膠囊式分頁切換、系統字型
（-apple-system／PingFang TC／Microsoft JhengHei）、大圓角與大留白。同時支援淺色／深色模式，
會自動依作業系統設定切換（也可在 Streamlit 右上角選單手動指定）。主題色彩、圓角、字型定義在
[.streamlit/config.toml](.streamlit/config.toml)，分頁膠囊樣式與按鈕互動效果等 config.toml 管不到的
細節則在 [src/theme.py](src/theme.py) 補強，兩者共同套用於台股、美股兩個頁面。

## 介面配置

主畫面分成兩個分頁：

- **🔍 快速查詢股票**：直接輸入股票代號或公司名稱（支援部分比對）即可看到該股票的完整資料
  （ROE 趨勢圖、五點原則逐項檢核、同業比較），**不受篩選條件影響**，也不需要股票有出現在目前篩選結果中。
  找到多筆符合的公司時可從下拉選單選擇。搜尋依據的是股票代號與公司**登記全名**，若輸入常用簡稱（例如「台積電」）
  找不到，可改用股票代號（例如「2330」）查詢。
- **📊 篩選結果與個股詳情**：側邊欄篩選條件套用後的結果表格、下載按鈕，以及點表格列或用下拉選單挑選後的個股詳細卡片。

這兩個分頁刻意分開，是因為快速查詢一旦選到股票就會展開一整張詳細卡片（圖表＋檢核清單＋同業比較表），
如果和篩選結果放在同一個直向捲動頁面，篩選結果會被這張卡片往下推很多，體驗不好；分頁讓兩種情境
（「查一檔特定股票」vs「瀏覽篩選出的清單」）各自獨立，互不影響彼此的畫面位置。

側邊欄裡「🎯 延伸判準：預期報酬率（IRR）」與「💰 加分：估價區間篩選」預設是收合的展開區塊——
這兩項不是五點原則本身、只是額外的加分判準，收合起來可以讓核心的 ①②③④ 篩選條件更快被看到，
需要用時點開即可，設定值不會因為收合而重設。

每張個股詳細卡片最下方都有「⬆️ 回到最上方」連結，方便看完落落長的同業比較表之後快速跳回頁首，不用手動往上滑。

## 台股與美股的差異

美股清單（`uslist.xlsx`）欄位命名與台股清單相同（同一套工具產生），但有以下差異，已在美股頁面中對應調整：

- **淨利門檻**：改用課程附錄「稅前淨利國際級 > USD 75M」延伸判準（預設 75 百萬），而非台股 5 億元台幣的門檻。
- **財報幣別**：美股清單涵蓋多國掛牌／ADR 公司，`財報幣別` 並非全為 USD，頁面新增「財報幣別」篩選器，且淨利數字未做幣別換算，跨幣別比較時請留意。
- **查證連結**：台股個股詳情連結至公開資訊觀測站（MOPS），美股則連結至 Yahoo Finance（美股橫跨多國，沒有單一公開資訊入口）。
- **ROE1~ROE5 時間順序**：沿用台股已確認的「近→遠」順序假設，但尚未針對美股個別驗證，僅供參考。
- **產業類別（SECTOR）改成兩層式篩選**：先選「產業大分類」（約 10~12 類）縮小範圍，再從細分產業清單挑選，避免一次面對上百個選項。美股細分產業額外附上中文翻譯（格式為「中文（English）」），方便不熟英文財經術語的使用者選取；對照表在 [src/us_sector_i18n.py](src/us_sector_i18n.py)（美股）與 [src/tw_sector_groups.py](src/tw_sector_groups.py)（台股），若之後資料出現新的 SECTOR 字串，測試會提醒需要補上對照。
- **同業比較的分組依據不同**：美股清單多了 `Industry`（細分產業）欄位，比 `SECTOR` 更精準（例如 SECTOR「Finance」高達近 1900 家，Industry 則細分成「Regional Banks」「Major Banks」等數百家等級的分組），因此美股頁面的「同業比較」是依 `Industry` 分組，而篩選側邊欄與「③不會變的公司」檢核項目仍是依 `SECTOR` 判斷。台股清單沒有 `Industry` 欄位，同業比較維持依 `SECTOR` 分組。

## 已知限制

本系統只能自動判斷五點原則中的 ①②④（淨利部分），③（不會變的公司）僅提供產業分類供人工判斷，
④（上市滿 2 年）與 ⑤（董監持股 ≥10%）完全無法自動判斷，須自行至
[公開資訊觀測站](https://mops.twse.com.tw) 或 GoodInfo 查證。詳見 [SPEC.md](SPEC.md) 第 9 節。
